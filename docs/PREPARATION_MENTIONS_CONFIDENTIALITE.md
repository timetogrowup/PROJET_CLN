## Confidentialité — contenu fonctionnel à finaliser

Responsable du traitement : CLN Performance, coordonnées ci-dessus.

Données de contact : nom, adresse email, organisation facultative, message et éléments du diagnostic que le visiteur choisit d'inclure. Champs obligatoires identifiés dans le formulaire.

Finalités : répondre à la demande et organiser les échanges associés ; sécurité et prévention des soumissions abusives. Pas d'inscription à une newsletter par ce formulaire.

Base juridique à arrêter selon le traitement : mesures précontractuelles demandées par la personne pour une demande de prestation ; intérêt légitime pour les autres demandes et la sécurité. La case actuelle d'accord de recontact doit être mise en cohérence avec la base retenue, sans consentement marketing groupé.

Destinataires opérationnels : personnes habilitées de CLN Performance et prestataires techniques nécessaires. Le transport SMTP et la boîte mail sont chez OVHcloud ; les pages statiques sont sur GitHub Pages. Les informations des hébergeurs et les éventuels transferts doivent être documentés avec les contrats applicables.

Conservation : durée des échanges et politique de suppression à définir effectivement avant publication d'une promesse de durée. Ne pas annoncer une suppression automatique qui n'existe pas. Les compteurs antispam reposent sur une empreinte d'IP et des horodatages dans un dossier temporaire privé ; leur purge effective reste à examiner.

Diagnostic : une synthèse est conservée dans le localStorage du navigateur pour la reprise vers Contact. Un bouton permet de l'effacer sur la page Contact. Il faut préciser la durée de persistance réelle et vérifier le fonctionnement avant de publier cette information.

Droits : accès, rectification, effacement, limitation, opposition et, selon la base et les conditions applicables, portabilité ; demandes via contact@cln-performance.com. Possibilité de réclamation à la CNIL.
